## Must fix

1. **Observer routing creates tasks nobody can receive.** [session.ts](/Users/cheyrasmussen/jamsesh-p2/jamsesh/hub/src/session.ts:879) removes observers from product directives, then saves a `pending` directive even when `targets` is empty. [pair_agents](/Users/cheyrasmussen/jamsesh-p2/jamsesh/hub/src/brain/brain.ts:703) and the [parity path](/Users/cheyrasmussen/jamsesh-p2/jamsesh/hub/src/brain/brain.ts:933) can include observers and report those directives as sent. Select workers in both brain paths and refuse a product directive when filtering leaves no target; replace that test expectation.

2. **An interrupted reinstall can break working hooks.** [install-scripts.ts](/Users/cheyrasmussen/jamsesh-p2/jamsesh/hub/src/install-scripts.ts:343) downloads directly onto the installed `hook.sh`. A transfer that fails after writing bytes leaves a partial script; `set -e` stops setup while existing Claude hooks still invoke it. Download to a private temporary file, verify success, then rename it into place. The [MCP remove-then-add sequence](/Users/cheyrasmussen/jamsesh-p2/jamsesh/hub/src/install-scripts.ts:372) also needs rollback if registration fails.

3. **Prompt replay can duplicate a recorded prompt.** [hub.ts](/Users/cheyrasmussen/jamsesh-p2/jamsesh/hub/src/hub.ts:498) retains only the latest 500 prompt IDs. If the hub records a prompt but its answer is lost, 500 later prompts can evict its ID before the outbox replays it within its ten-minute lifetime. The replay then records it again, contrary to [SPEC.md](/Users/cheyrasmussen/jamsesh-p2/jamsesh/SPEC.md:384). Keep deduplication IDs durably for at least the replay lifetime and test eviction before replay.

4. **The instruction-file safety check still has a race.** [install-scripts.ts](/Users/cheyrasmussen/jamsesh-p2/jamsesh/hub/src/install-scripts.ts:222) re-reads before `unlink` or `rename`, but an editor can save after that read and before the filesystem operation. That save is then deleted or overwritten. The concurrency tests edit *before* the re-read, so they cannot catch this case. If preserving every concurrent edit is a requirement, remove the automatic rewrite in favor of an editor-mediated migration that detects conflicts.
