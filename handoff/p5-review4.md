## Production blockers

1. **A new pairing can take an unclaimed person’s voiceprint.** [http.ts](/Users/cheyrasmussen/jamsesh-p5/jamsesh/hub/src/http.ts:446) rejects a claim only while another unrevoked browser credential or the host window holds that person. Once the old pairing is revoked—or for a stored person with no holder—any browser with the room’s general join code can claim the person’s public ID. The owner check at [line 505](/Users/cheyrasmussen/jamsesh-p5/jamsesh/hub/src/http.ts:505) then permits voiceprint GET, PUT, and DELETE. The [new test](/Users/cheyrasmussen/jamsesh-p5/jamsesh/hub/test/phase5-round3.test.ts:46) explicitly accepts a claim after revocation. **Fix:** bind a replacement credential through an explicit host-approved transfer or proof held by the person; test voiceprint access after a hostile claim. An offline, unrevoked credential does block the claim.

2. **Per-host Share consent can still be impersonated.** The Mac keys approval by the reached address and a host-supplied ID ([main.rs](/Users/cheyrasmussen/jamsesh-p5/jamsesh/app/src-tauri/src/main.rs:937), [voiceprints.rs](/Users/cheyrasmussen/jamsesh-p5/jamsesh/app/src-tauri/src/voiceprints.rs:263)). A host later serving the same LAN address and port can report the approved host’s public ID; [share](/Users/cheyrasmussen/jamsesh-p5/jamsesh/app/src-tauri/src/voiceprints.rs:233) then returns the samples without a dialog. A declined host at a different key remains denied. Showing the address helps with the first decision but cannot authenticate later connections. **Fix:** pin a persistent host public key at approval and verify possession before reusing consent; bind the first key to the person’s confirmed join.

3. **Reset freshness still relies on the sender’s clock.** [hub.ts](/Users/cheyrasmussen/jamsesh-p5/jamsesh/hub/src/hub.ts:397) accepts `updatedAt` up to 60 seconds ahead. A genuinely pre-reset copy exported by a host whose clock is 30 seconds fast can pass after Reset and restore the deleted samples. The test tries an hour ahead, missing the accepted interval. **Fix:** use a host-issued reset generation or require a new deliberate enrollment after Reset; test a stale copy with plausible clock skew.

4. **Reset misses audio and history that can teach the voice again.** [forgetVoice](/Users/cheyrasmussen/jamsesh-p5/jamsesh/hub/src/audio/pipeline.ts:605) clears candidates but does not mark open or in-flight groups, which can resume at [autoEnroll](/Users/cheyrasmussen/jamsesh-p5/jamsesh/hub/src/audio/pipeline.ts:318) after Reset. Separately, [scrubEmbeddings](/Users/cheyrasmussen/jamsesh-p5/jamsesh/hub/src/store.ts:245) removes only events already attributed to that person; correcting an older “Someone” line later uses its retained embedding at [assign](/Users/cheyrasmussen/jamsesh-p5/jamsesh/hub/src/audio/pipeline.ts:583). **Fix:** gate all learning by the person’s reset generation and the source audio’s capture time, and test both in-flight transcription and correction of an old unlabeled line.

5. **A failed device-copy deletion is hidden on reset rejection.** On a 409, [pushCopy](/Users/cheyrasmussen/jamsesh-p5/jamsesh/web/src/shared/voiceprint.ts:147) catches and discards `forgetCopy` failure. The stale copy remains available for another host while sync appears finished. The explicit Reset button does report deletion failure; this path does not. **Fix:** propagate the deletion failure and keep sync unresolved until the copy is removed or the person is told how to clear it.

6. **Dedupe still discards distinct speech.** [sameWords](/Users/cheyrasmussen/jamsesh-p5/jamsesh/hub/src/audio/pipeline.ts:679) treats any one- or two-word insertion as the same line when durations are close; [mergeTwin](/Users/cheyrasmussen/jamsesh-p5/jamsesh/hub/src/audio/pipeline.ts:368) then merges matching voices on different laptops. It also merges an exact phrase repeated by the *same* speaker within three seconds, even when the recordings are separate. The added-word [test](/Users/cheyrasmussen/jamsesh-p5/jamsesh/hub/test/dedupe.test.ts:126) uses a 900 ms duration difference, so it avoids the accepting branch. **Fix:** establish that copies contain the same acoustic event, rather than using words, voice, and a three-second window alone; test close-duration additions and same-speaker repetition.

7. **Voiceprint sync can finish before identity registration.** [ClientView.tsx](/Users/cheyrasmussen/jamsesh-p5/jamsesh/web/src/client/ClientView.tsx:39) starts sync before its `/devices` registration effect. The registration waits for outbox loading ([hub.ts](/Users/cheyrasmussen/jamsesh-p5/jamsesh/web/src/shared/hub.ts:407)); an early voiceprint GET gets 403 before the credential is bound to the person. [useVoiceprintSync](/Users/cheyrasmussen/jamsesh-p5/jamsesh/web/src/shared/voiceprint.ts:191) marks that person done even after failure and never retries. **Fix:** await acknowledged registration, then sync; retry on reconnect and identity changes.

8. **Two model error paths fail open or never finish.** A missing or malformed Parakeet manifest is regenerated from whatever extracted files exist and accepted ([parakeet.ts](/Users/cheyrasmussen/jamsesh-p5/jamsesh/hub/src/audio/parakeet.ts:52)); its test blesses arbitrary files without a manifest. A corrupt pinned Whisper model supplied through `JAMSESH_WHISPER_MODEL` outside the managed folder is returned even after it enters the bad-file set, so [goodModel](/Users/cheyrasmussen/jamsesh-p5/jamsesh/hub/src/audio/whisper.ts:133) hashes it indefinitely. **Fix:** verify Parakeet files against independently pinned hashes or reverify the archive, and apply the Whisper skip set and plausibility check to the chosen path. Test both failures.

## Design, tests, and docs

A previously approved host may replace the Mac’s portable copy without another decision ([voiceprints.rs](/Users/cheyrasmussen/jamsesh-p5/jamsesh/app/src-tauri/src/voiceprints.rs:157)). Its validation checks shape and finite numbers but accepts zero vectors and arbitrary model names. Tighten validation to the hub’s model and nonzero normalized samples, and decide explicitly whether approval grants a host ongoing authority to replace a copy shared with future rooms.

Browser storage writes swallow errors ([voiceprint.ts](/Users/cheyrasmussen/jamsesh-p5/jamsesh/web/src/shared/voiceprint.ts:63)). A failed consent write or copy write can be reported as success; a failed “off” write can leave consent on and allow a later pull to recreate the copy. Make choice and copy writes report failure and verify the saved value. Delete the manifest “accept once” branch unless legacy files can be independently verified. If `MediaRecorder.start()` throws, [Profile.tsx](/Users/cheyrasmussen/jamsesh-p5/jamsesh/web/src/client/Profile.tsx:115) stops the tracks but leaves its interval running; clear both timers in that catch.

Of the eight production findings in `p5-review3.md`, **6 and 7 are fixed in code** (WAV-derived levels; abort and idle timeout), and **8 is fixed in the bundle script** with the supplied pinned-build and `--help` verification. **3 has native decisions for destructive actions and first trust, but still permits unchecked replacement by an approved host.** **1, 2, 4, and 5 remain partial** for the reasons above. The QR known-host branch was removed. The Parakeet manifest and recorder fixes remain partial.

[SPEC.md](/Users/cheyrasmussen/jamsesh-p5/jamsesh/SPEC.md:1367) still says consent is keyed by host ID alone; [line 1165](/Users/cheyrasmussen/jamsesh-p5/jamsesh/SPEC.md:1165) says devices send level and noise values. Update both. `git diff --check` also reports a blank line at EOF in `web/test/mic.echo.test.ts`.

I could not verify native dialogs, real microphones, the full packaged app, or a fresh-Mac model download; those need an end-to-end release check. The working tree remains clean.
