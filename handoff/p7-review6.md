## Must fix before shipping

1. **Approval can claim a person’s page as an applied proposal.** [service.ts:738](/Users/cheyrasmussen/jamsesh-p7/jamsesh/hub/src/wiki/service.ts:738) reconciles a pending write by comparing Markdown, and [service.ts:846](/Users/cheyrasmussen/jamsesh-p7/jamsesh/hub/src/wiki/service.ts:846) makes the same assumption even when no write was attempted. If a person creates a proposed page with identical text before approval, Accept records the proposal as applied without writing its category or sources, then marks its sources read. Conversely, if a proposal write lands but a person edits the page before reconciliation, the text comparison can erase evidence of the landed write from the approval record. Give each proposed page write a durable identity that survives later edits; reconcile against that identity, and treat an independently written page as stale. Test both sequences.

2. **Session shutdown can lose the final transcript source.** [service.ts:499](/Users/cheyrasmussen/jamsesh-p7/jamsesh/hub/src/wiki/service.ts:499) serializes final capture behind the current ingest, whose model call can take 120 seconds. [hub.ts:227](/Users/cheyrasmussen/jamsesh-p7/jamsesh/hub/src/hub.ts:227) waits only 25 seconds for that queued flush, then [index.ts:111](/Users/cheyrasmussen/jamsesh-p7/jamsesh/hub/src/index.ts:111) exits. Conversation after the current ingest’s capture has no source if the next launch starts a new session. Capture and persist the tail before waiting on model work, or recover uncaptured events from the prior session. Test shutdown while an ingest model call is blocked.
