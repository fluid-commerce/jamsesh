## Production blockers

1. **A newly paired browser can claim another person’s voiceprint.** [http.ts](/Users/cheyrasmussen/jamsesh-p5/jamsesh/hub/src/http.ts:442) binds a browser credential to any existing `personId` supplied in its first `/api/devices` request. The person IDs are available in room state. The voiceprint owner check then trusts that credential, allowing the browser to GET, PUT, or DELETE that person’s print ([http.ts](/Users/cheyrasmussen/jamsesh-p5/jamsesh/hub/src/http.ts:500)). **Fix:** require proof or explicit host approval before binding a credential to an existing person; test a newly paired browser claiming a victim and attempting all three operations.

2. **The per-host Share decision can be reused by a hostile host.** The approval is keyed only by `hostId` ([voiceprints.rs](/Users/cheyrasmussen/jamsesh-p5/jamsesh/app/src-tauri/src/voiceprints.rs:172)). That ID is supplied by the host through a public endpoint ([http.ts](/Users/cheyrasmussen/jamsesh-p5/jamsesh/hub/src/http.ts:172)). A different host can report an already approved ID; `voiceprint_share` then returns the Mac’s copy without a new dialog. **Fix:** bind approval to the app-selected host address and an authenticated host identity, and show that address in the dialog. Test a second host that copies the first host’s ID.

3. **Host-served code can alter the Mac’s local copy without a native decision.** The `client` page can invoke `voiceprint_put`, `voiceprint_consent(false)`, and `voiceprint_forget`; [voice_owner](/Users/cheyrasmussen/jamsesh-p5/jamsesh/app/src-tauri/src/main.rs:917) verifies the page’s person ID but no user action. The capability grants those commands to the host-served page ([voiceprint.json](/Users/cheyrasmussen/jamsesh-p5/jamsesh/app/src-tauri/capabilities/voiceprint.json:5)). A hostile host can erase or poison the copy that travels to later rooms. **Fix:** move local consent and destructive copy changes into trusted app UI, and validate host-derived updates before accepting them.

4. **Reset can restore a supposedly forgotten voice.** Reset clears stored samples but leaves unconfirmed auto-enrollment candidates in memory ([pipeline.ts](/Users/cheyrasmussen/jamsesh-p5/jamsesh/hub/src/audio/pipeline.ts:104), [hub.ts](/Users/cheyrasmussen/jamsesh-p5/jamsesh/hub/src/hub.ts:411)); the next matching line commits the pre-reset candidate. The older-copy guard also trusts the caller’s `updatedAt`, so a future timestamp bypasses it ([hub.ts](/Users/cheyrasmussen/jamsesh-p5/jamsesh/hub/src/hub.ts:397)). Finally, a failed device-copy deletion is silently treated as success ([voiceprint.ts](/Users/cheyrasmussen/jamsesh-p5/jamsesh/web/src/shared/voiceprint.ts:115)). **Fix:** clear candidates on reset, use a reset generation rather than client wall time, and surface deletion failures. Test candidate → reset → new line, a forged timestamp, and a failed local deletion.

5. **Related speech can still disappear in dedupe.** With embeddings available, “Make it blue now” and “Make it blue now after lunch” score 1.0 under the set-based text comparison; if spoken by the same person on different laptops within three seconds, [mergeTwin](/Users/cheyrasmussen/jamsesh-p5/jamsesh/hub/src/audio/pipeline.ts:368) merges them. The regression uses voice matching *off* ([dedupe.test.ts](/Users/cheyrasmussen/jamsesh-p5/jamsesh/hub/test/dedupe.test.ts:50)), so it cannot catch this path. **Fix:** require token-level agreement that preserves added words or clauses, and test with matching voice embeddings.

6. **Audio ownership was fixed, but acoustic values are still caller-controlled.** `/audio` now checks device ownership, then forwards query-string `level` and `noise` ([http.ts](/Users/cheyrasmussen/jamsesh-p5/jamsesh/hub/src/http.ts:464)). [ingest](/Users/cheyrasmussen/jamsesh-p5/jamsesh/hub/src/audio/pipeline.ts:152) prefers those values over WAV measurements; they determine the cleanest copy and contribute to the speaker label. A paired device can exaggerate its own level and teach the wrong voice. **Fix:** derive both values from decoded audio and test forged query values, including non-finite ones.

7. **Parakeet’s off/on fix still waits indefinitely on a stalled download.** [downloadVerified](/Users/cheyrasmussen/jamsesh-p5/jamsesh/hub/src/audio/models.ts:34) checks cancellation only when a body chunk arrives; its fetch has no abort signal or timeout. After Off then On, [syncFastEngine](/Users/cheyrasmussen/jamsesh-p5/jamsesh/hub/src/audio/transcribe.ts:142) waits for that old start, which may never finish. **Fix:** abort the request on Off and enforce a download timeout; test a response that stalls before its next chunk.

8. **The release check does not prove a pinned Whisper binary.** [build-whisper.sh](/Users/cheyrasmussen/jamsesh-p5/jamsesh/app/build-whisper.sh:15) accepts any executable accompanied by a stamp containing its own SHA and the pinned commit string. [bundle-hub.sh](/Users/cheyrasmussen/jamsesh-p5/jamsesh/app/bundle-hub.sh:19) therefore bundles a substituted binary with a matching substituted stamp. The test explicitly accepts a shell script under that condition ([transcription.test.ts](/Users/cheyrasmussen/jamsesh-p5/jamsesh/hub/test/transcription.test.ts:656)). **Fix:** rebuild from the pinned source during packaging or compare against an independently trusted artifact digest; make the substituted-binary test fail.

## Design and test concerns

- **Should-fix:** [findModel](/Users/cheyrasmussen/jamsesh-p5/jamsesh/hub/src/audio/parakeet.ts:26) checks installed Parakeet files by name only. The downloaded archive is verified, but later changes to extracted files go unchecked. Verify a manifest of extracted file hashes before loading.
- **Should-fix:** [Profile.tsx](/Users/cheyrasmussen/jamsesh-p5/jamsesh/web/src/client/Profile.tsx:107) acquires a microphone stream inside a `try`; if `MediaRecorder` construction or `start()` throws, the `catch` does not stop its tracks. Stop the stream on every failure and handle recorder error events.
- Delete the unused production “known host” branch in [scanGoes](/Users/cheyrasmussen/jamsesh-p5/jamsesh/web/src/connect/joinHelp.ts:28), or pass it actual known hosts. The browser caller always uses the default empty list; its test exercises a path users cannot reach.
- The test gate now invokes hub, web, and Tauri suites, but model-dependent suites can skip. The provenance test asserts the opposite of the claimed invariant. Add the failure tests above before relying on a green gate.
