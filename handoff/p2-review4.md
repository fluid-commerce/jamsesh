## Must fix before shipping

1. **An installed MCP server still tells an uninvited chat to join.** [mcp.ts](/Users/cheyrasmussen/jamsesh-p2/jamsesh/hub/src/mcp.ts:339) sends “Call jam_join first” in the server’s initialization instructions. That conflicts with the Phase 2 rule that a chat joins only when its person asks. Change the initialization text to say to wait for that request; put the working rules after `jam_join`.

2. **Observers can claim work through `jam_update`.** [mcp.ts](/Users/cheyrasmussen/jamsesh-p2/jamsesh/hub/src/mcp.ts:471) passes `workstream` to [postUpdate](/Users/cheyrasmussen/jamsesh-p2/jamsesh/hub/src/session.ts:648), which calls `claim` without the observer check used by `jam_claim`. That quiet claim also skips the notice for work nobody asked for. Enforce the role in `Session.claim`, and announce a new claim made through an update. Test both paths.

3. **A burst of decisions can be lost from hook delivery.** [hub.ts](/Users/cheyrasmussen/jamsesh-p2/jamsesh/hub/src/hub.ts:537) requests ten decisions; [roomDecisions](/Users/cheyrasmussen/jamsesh-p2/jamsesh/hub/src/session.ts:1010) keeps the newest ten. If eleven relevant decisions arrive before a hook call, the oldest is omitted and acknowledgement advances the cursor past it. Page relevant decisions oldest first before advancing the cursor. Test a burst larger than ten.

4. **Reinstall can delete someone else’s Claude hook.** [install-scripts.ts](/Users/cheyrasmussen/jamsesh-p2/jamsesh/hub/src/install-scripts.ts:401) removes an entire hook entry whenever its encoded JSON contains `jamsesh`. A user hook whose path or argument contains that word is removed; a group containing both JamSesh’s hook and a user hook is removed wholesale. Match JamSesh’s own hook command and remove only that command.

5. **Stripping the old instructions block can expose private file contents.** [STRIP_BLOCK_PL](/Users/cheyrasmussen/jamsesh-p2/jamsesh/hub/src/install-scripts.ts:210) writes the replacement to a predictable temporary path before setting its mode. A new temp file can briefly be world-readable under a normal umask; an existing temp file keeps its old mode while being overwritten. Create an exclusive temp file in the same directory at mode `0600`, write it, then apply the source mode and rename.

6. **A valid TOML comment can break Codex configuration on reinstall.** The scanner in [install-scripts.ts](/Users/cheyrasmussen/jamsesh-p2/jamsesh/hub/src/install-scripts.ts:445) counts `"""` on comment lines as a multiline string delimiter. A comment containing `"""` before `[mcp_servers.jamsesh]` makes the scanner retain the old table and append a duplicate. Ignore comments when tracking string delimiters, and test this valid TOML case.

7. **An invalid named reassignment silently chooses someone else.** [reassignDirective](/Users/cheyrasmussen/jamsesh-p2/jamsesh/hub/src/session.ts:811) falls back to affinity when `to` names an unavailable or unknown agent. The API can report success after assigning work to a person the caller did not choose. Reject an invalid explicit `to`; use affinity only when `to` is absent.

## Design and verification

[DevProxy.refresh](/Users/cheyrasmussen/jamsesh-p2/jamsesh/hub/src/devproxy.ts:205) awaits a health check, then applies its result by id. If an agent replaces that registration during the wait, a stale check can mark the replacement down or remove it. Re-read the registration and verify its target before applying the result. This is a **should fix**.

The Round 4 review’s eight must-fixes and three should-fixes are present in the pinned commit. The new tests cover those cases but miss the observer update path, decision bursts, unrelated hook removal, and TOML comments above. `findAgentByCwd` and the `onListen` wrapper have no production callers; delete them if they are no longer part of a supported interface.

I did not run tests because they write temporary files and this review was explicitly read-only. I could not verify the full installed-hook flow in a real room or across two Macs. The referenced `craftrules/AGENTS.md` was unavailable at its documented sibling locations.
