## Production blockers

1. **A paired client can impersonate another microphone.** [`http.ts`](/Users/cheyrasmussen/jamsesh-p5/jamsesh/hub/src/http.ts:458) accepts the `deviceId`, level, and noise values from an audio upload without checking that the caller owns that device. The `/devices` route checks ownership, but `/audio` does not. The pipeline then uses the named device’s owner to label speech and potentially teach that person’s voiceprint ([`pipeline.ts`](/Users/cheyrasmussen/jamsesh-p5/jamsesh/hub/src/audio/pipeline.ts:519)). Require an existing device owned by the caller and derive acoustic levels from the WAV. Test cross-device uploads.

2. **The Mac copy is not isolated by person.** [`voiceprints.rs`](/Users/cheyrasmussen/jamsesh-p5/jamsesh/app/src-tauri/src/voiceprints.rs:43) uses a trimmed, lowercased, 80-character name prefix as the file key. Two people named Alex on a shared Mac therefore share both consent and embeddings. The acknowledged hostile-host case is also confirmed: a host that presents the same name can receive the existing copy once that window is identified as its Alex. A per-host prompt would address that hostile-host case, but not two distinct people with the same name. Use a stable person identity, or keep host/person copies separate until identity is explicitly linked; reject ambiguous names.

3. **Turning consent off can race with a copy write.** [`voiceprints.rs`](/Users/cheyrasmussen/jamsesh-p5/jamsesh/app/src-tauri/src/voiceprints.rs:81) uses one `.json.part` path and an unlocked load–modify–save sequence for both `set_consent` and `put`. Concurrent Tauri calls can read `consent: true`; a later `put` can restore the copy after “off,” or one rename can fail. Serialize operations per person and use a unique temporary file. Also surface write failures: [`setCarryAllowed()`](/Users/cheyrasmussen/jamsesh-p5/jamsesh/web/src/shared/voiceprint.ts:102) currently swallows them while the checkbox changes state.

4. **“Forget their voice” does not forget the recoverable embeddings.** The reset route clears voiceprint samples ([`http.ts`](/Users/cheyrasmussen/jamsesh-p5/jamsesh/hub/src/http.ts:512)), but speech events retain an embedding ([`hub.ts`](/Users/cheyrasmussen/jamsesh-p5/jamsesh/hub/src/hub.ts:257)). A later correction reads it and creates a new sample ([`pipeline.ts`](/Users/cheyrasmussen/jamsesh-p5/jamsesh/hub/src/audio/pipeline.ts:586)). A consenting device also retains its copy and can push it back on the next join. Define reset semantics across host events and device copies, scrub retained embeddings for that person, and prevent an old copy from silently restoring a reset print.

5. **The dedupe voice check is optional when it needs to be decisive.** [`pipeline.ts`](/Users/cheyrasmussen/jamsesh-p5/jamsesh/hub/src/audio/pipeline.ts:357) merges nearby lines from different devices when their text overlaps; it rejects a different voice only *if both embeddings exist*. With voice matching off, “make it blue now” and “make it blue now after lunch” pass the containment-based text score and can become one line. Require positive voice agreement for this merge, or retain both lines when it is unavailable. Test overlapping, related sentences with the speaker model off.

6. **An expired group can still discard a distinct line by time alone.** After the finalized group ages out, [`ingest()`](/Users/cheyrasmussen/jamsesh-p5/jamsesh/hub/src/audio/pipeline.ts:189) returns without transcribing if any stored utterance has a matching time span. Two speakers on different devices at the same time can meet that condition. The “expired group keeps the line” test uses a 1.5-second skew that avoids this branch. Remove the time-only discard; retain or verify the late line with text and voice evidence.

7. **Short copies still duplicate under clock skew.** [`sameUtterance()`](/Users/cheyrasmussen/jamsesh-p5/jamsesh/hub/src/audio/pipeline.ts:663) rejects spans shifted by a second, while [`mergeTwin()`](/Users/cheyrasmussen/jamsesh-p5/jamsesh/hub/src/audio/pipeline.ts:368) requires four words. Two laptops hearing “Looks good” with clocks 1.5 seconds apart can show it twice. Add short-utterance skew cases and a conservative merge rule for them.

8. **The read-suppression window remains open on failure.** [`beginEnrolment()`](/Users/cheyrasmussen/jamsesh-p5/jamsesh/hub/src/audio/pipeline.ts:321) opens a 90-second window, but [`endEnrolment()`](/Users/cheyrasmussen/jamsesh-p5/jamsesh/hub/src/audio/pipeline.ts:327) is reached only after successful enrollment. Camera or recording failure, a rejected quiet sample, or upload failure leaves script-like ordinary speech eligible for suppression long after the person stopped reading. Add an explicit end/cancel request in a `finally` path and test each failure.

9. **The release bundle does not establish the provenance it claims.** [`bundle-hub.sh`](/Users/cheyrasmussen/jamsesh-p5/jamsesh/app/bundle-hub.sh:17) copies any executable already named `whisper-server`; the pinned source-commit check in `build-whisper.sh` runs only when that file is absent. [`install.sh`](/Users/cheyrasmussen/jamsesh-p5/jamsesh/install.sh:57) also accepts an existing WeSpeaker model without a checksum and bundles it. Rebuild or verify the binary against a recorded build artifact, and pin and verify the speaker model before reuse and packaging.

10. **A quick off/on toggle can leave the faster engine off.** [`transcribe.ts`](/Users/cheyrasmussen/jamsesh-p5/jamsesh/hub/src/audio/transcribe.ts:128) stops an in-progress Parakeet start without invalidating `starting`. Re-enabling before that promise settles reuses the canceled attempt; nothing retries. Generation-tag starts or restart after cancellation when the setting is still on, with a held-download toggle test.

## Design, tests, and documentation

- The host Settings page offers **Reset** for every person ([`Settings.tsx`](/Users/cheyrasmussen/jamsesh-p5/jamsesh/web/src/shared/Settings.tsx:262)), while the API permits only the caller’s own voiceprint to be deleted. Hide the action where it cannot succeed, or provide a separately specified host-admin action.
- Bonjour resolutions launch overlapping checks of every advert ([`discover.rs`](/Users/cheyrasmussen/jamsesh-p5/jamsesh/app/src-tauri/src/discover.rs:212)). Results have no generation guard; two stale failures can hide a host that answered a newer check. Serialize checks per host or ignore stale results.
- The strongest speaker tests use `test.skipIf(!CAN_SIM)`, and the root `test` script runs only `bun test hub` ([`package.json`](/Users/cheyrasmussen/jamsesh-p5/jamsesh/package.json:8)). Add deterministic failure tests for the cases above and run web and Tauri tests in the release gate. The existing skew tests use long sentences, and the reset and concurrent-consent paths are untested.
