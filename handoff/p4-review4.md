## Must-fix

1. **A file can enable agent work when the person asked only for an explanation.** [brain.ts](/Users/cheyrasmussen/jamsesh-p4/jamsesh/hub/src/brain/brain.ts:1546) treats any affirmative occurrence of “build,” “make,” or “fix” as permission to offer `create_directive`; [intent.ts](/Users/cheyrasmussen/jamsesh-p4/jamsesh/hub/src/brain/intent.ts:26) checks negation, but not whether the verb describes the requested action. A read-only probe returned `true` for “Summarize how to build the header in this file” and “Explain what we need to fix in this document.” The execution check repeats the same predicate, so it does not close the opening for attached instructions to steer a model call. Require an explicit instruction to delegate work, and test explanatory questions containing work verbs.

2. **Curation can replace a fact in another scope.** [curation.ts](/Users/cheyrasmussen/jamsesh-p4/jamsesh/hub/src/brain/curation.ts:170) pairs an addition with a superseded fact using similarity alone. “Desktop header uses option A” and “Mobile header uses option B” score `0.75` while `sameScope` returns `false`. A named replacement then bypasses the scope check in [board.ts](/Users/cheyrasmussen/jamsesh-p4/jamsesh/hub/src/board.ts:169), and [replace](/Users/cheyrasmussen/jamsesh-p4/jamsesh/hub/src/board.ts:391) skips kind and workstream validation for matched cards. Editing a matched card’s scope before Replace has the same effect. Check kind, workstream, and textual scope when pairing and again against the final edited card before retirement.

3. **The context lock can have two live owners.** [carryover.ts](/Users/cheyrasmussen/jamsesh-p4/jamsesh/hub/src/carryover.ts:139) deletes a lock solely because its mtime is over ten seconds old. A paused writer can resume after a second process has deleted its lock and acquired another; both can pass the `activeAt` comparison and rename, and the first can remove the second’s lock in `finally`. Use an ownership-aware lock with verified stale-owner recovery. Test a writer paused past the takeover threshold.

4. **A failed carry-over save can be reported as a clean shutdown.** [projectkeeper.ts](/Users/cheyrasmussen/jamsesh-p4/jamsesh/hub/src/projectkeeper.ts:31) ignores `writeProjectContext` returning `false` and catches write errors. [Hub.shutdown](/Users/cheyrasmussen/jamsesh-p4/jamsesh/hub/src/hub.ts:185) therefore treats the keeper step as successful and can exit zero while the next session will read old context. Distinguish intentional skips from failed writes and propagate failures to shutdown.

5. **Six valid PDFs can become one 120 MB model request.** [attachments.ts](/Users/cheyrasmussen/jamsesh-p4/jamsesh/hub/src/attachments.ts:106) limits the count and each file, while [brainInput](/Users/cheyrasmussen/jamsesh-p4/jamsesh/hub/src/attachments.ts:138) retains every PDF’s bytes as a model part. The text budget does not limit those parts. Cap aggregate attachment bytes for a message or process documents into bounded text before the router pass. Test the six-PDF boundary.

6. **Loopback attachment reads bypass the documented pairing requirement.** [http.ts](/Users/cheyrasmussen/jamsesh-p4/jamsesh/hub/src/http.ts:193) treats every local request as authenticated, and [the fetch route](/Users/cheyrasmussen/jamsesh-p4/jamsesh/hub/src/http.ts:575) adds no host-window or credential check. An unpaired local process can read state to obtain attachment IDs, then fetch their contents. [SPEC §12.6](/Users/cheyrasmussen/jamsesh-p4/jamsesh/SPEC.md:1733) promises 401 for unpaired fetches. Require a host-window key or a current session credential for this route, including on loopback.

- **Should-fix:** [withAttachments](/Users/cheyrasmussen/jamsesh-p4/jamsesh/hub/src/brain/brain.ts:322) returns `files: false` if all referenced bytes have become unreadable. Keep the attachment tool restrictions active and tell the person the files could not be read.
- **Should-fix:** Delete the optional, unreviewed write path in [applyCuration](/Users/cheyrasmussen/jamsesh-p4/jamsesh/hub/src/brain/curation.ts:108). Production supplies a hold, but omitting it lets the exported function rewrite or retire accepted facts without the board. Require the hold and remove those branches.
- The prior round’s negation and option-polarity logic, forward curation cursor, retirement snapshots, schema validation, targeted Retire action, PDF page-content reader, bundled-worker path, and glossary use are present. The scope and lock guarantees remain incomplete under the cases above. The two stated raw-room-talk exceptions remain deliberate.
- The tests cover ordinary routing, attachment authorization from remote devices, and fast context writes. They do not cover explanatory file requests that enable work, cross-scope curation pairing, aggregate PDF size, stale-lock takeover, failed keeper writes, or unpaired loopback fetches. I ran read-only predicate probes, including the `0.75` similarity/`sameScope: false` case. I did not run suites because they create files and this review is report-only. I could not independently repeat the STATUS claims about the live gateway or compiled PDF worker in a real room.
