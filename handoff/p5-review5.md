## Production blockers

Review target: `fd8f5e73ad23`. The working tree is clean.

1. **A small WAV can exhaust the hub’s memory.** [wav.ts](/Users/cheyrasmussen/jamsesh-p5/jamsesh/hub/src/audio/wav.ts:20) trusts the file’s sample rate, and [resample](/Users/cheyrasmussen/jamsesh-p5/jamsesh/hub/src/audio/wav.ts:68) allocates `frames × 16000 / sampleRate`. I verified that a 244-byte WAV claiming 1 Hz produces 1.6 million output frames. The [audio endpoint](/Users/cheyrasmussen/jamsesh-p5/jamsesh/hub/src/http.ts:467) accepts uploads from paired devices with a 64 MB body limit, which does not bound that allocation. **Fix:** validate WAV format fields and cap decoded frames, duration, and resampled bytes before allocating.

2. **Reset does not invalidate an enrollment already in progress.** [beginEnrolment](/Users/cheyrasmussen/jamsesh-p5/jamsesh/hub/src/audio/pipeline.ts:340) records no reset generation. If someone starts reading, resets their voice, then the recording arrives, [enrol](/Users/cheyrasmussen/jamsesh-p5/jamsesh/hub/src/audio/pipeline.ts:675) writes it with `Date.now()` after Reset. The [store gate](/Users/cheyrasmussen/jamsesh-p5/jamsesh/hub/src/store.ts:362) therefore accepts pre-reset speech. **Fix:** bind each read to the generation at `/voice/start` and reject its upload if Reset advanced it.

3. **Buffered audio still relies on a device-supplied time.** [ingest](/Users/cheyrasmussen/jamsesh-p5/jamsesh/hub/src/audio/pipeline.ts:185) sets `heardAt = min(arrival, input.t0)`. Clock synchronization in the browser improves `t0`, but it is still supplied by the uploader. A pre-reset clip with a timestamp ahead of the host that arrives after Reset passes `addVoiceSample`. The [test](/Users/cheyrasmussen/jamsesh-p5/jamsesh/hub/test/phase5-round4.test.ts:169) checks only that future `t0` is clamped to arrival, not that pre-reset audio is refused. **Fix:** attach a host-issued capture generation to queued segments and reject an older generation; test skewed, buffered audio across Reset.

4. **The acoustic dedupe rule is bypassed before it runs.** [ingest](/Users/cheyrasmussen/jamsesh-p5/jamsesh/hub/src/audio/pipeline.ts:196) groups overlapping segments by timestamps. [splitCrosstalk](/Users/cheyrasmussen/jamsesh-p5/jamsesh/hub/src/audio/pipeline.ts:258) separates them only when their spans shift by at least a second. Two different speakers with the same start and end times become one group; only its best recording is transcribed. `sameSound` is reached later in `mergeTwin`. The separate [hybrid echo drop](/Users/cheyrasmussen/jamsesh-p5/jamsesh/hub/src/audio/pipeline.ts:427) also uses time, words, and SNR without acoustic agreement. **Fix:** preserve distinct overlapping recordings through grouping and revisit, and require acoustic evidence before dropping a cross-location echo. Test genuinely simultaneous different speech; the named “two people at once” test places the lines nine seconds apart.

5. **The pinned host key does not protect sharing on the default plain-HTTP LAN path.** [voice_host](/Users/cheyrasmussen/jamsesh-p5/jamsesh/app/src-tauri/src/main.rs:937) verifies a signature fetched through that path, then [voiceprint_share](/Users/cheyrasmussen/jamsesh-p5/jamsesh/app/src-tauri/src/main.rs:978) returns plaintext samples to the host-served page. An active relay can forward the real host’s nonce and signature while substituting its own page and reading the returned samples. The SPEC discloses this limit; it remains a blocker for a feature used over LAN HTTP. **Fix:** require an authenticated HTTPS upstream for portable sharing, or move the transfer into a direct encrypted app-to-host channel that never gives samples to the page.

6. **An unknown host gets a stable cross-host identifier before Share consent.** [Kept.me](/Users/cheyrasmussen/jamsesh-p5/jamsesh/app/src-tauri/src/voiceprints.rs:57) is a persistent random ID. [for_page](/Users/cheyrasmussen/jamsesh-p5/jamsesh/app/src-tauri/src/voiceprints.rs:228) clears host answers and unshared samples but leaves `me`; [voiceprint_get](/Users/cheyrasmussen/jamsesh-p5/jamsesh/app/src-tauri/src/main.rs:970) returns it without a dialog. Any joined host can correlate the same Mac user across rooms. **Fix:** remove `me` from the page response; since it is never used for an ownership check, delete the stored field too.

7. **The Mac store’s lock does not cover the consent decision.** [share](/Users/cheyrasmussen/jamsesh-p5/jamsesh/app/src-tauri/src/voiceprints.rs:248) remembers an earlier `hosts[key] == true`, then reloads only `consent` before returning the copy. If the person switches keeping off and back on between those reads, host answers have been cleared, yet the pending Share returns samples without asking again. [put](/Users/cheyrasmussen/jamsesh-p5/jamsesh/app/src-tauri/src/voiceprints.rs:168) likewise checks host trust outside its final locked write. **Fix:** recheck both consent and that host’s current approval in the same locked operation that returns or writes samples; invalidate pending operations when consent or Reset changes.

8. **A successful push can be marked synced while the device still holds its old copy.** [pushCopy](/Users/cheyrasmussen/jamsesh-p5/jamsesh/web/src/shared/voiceprint.ts:151) ignores the result of [pullCopy](/Users/cheyrasmussen/jamsesh-p5/jamsesh/web/src/shared/voiceprint.ts:134), which catches GET, storage, and native-dialog failures. The [hook](/Users/cheyrasmussen/jamsesh-p5/jamsesh/web/src/shared/voiceprint.ts:211) then marks that person synced and does not retry. **Fix:** propagate a failed post-PUT pull, leave sync pending, and test a failed GET or native put after a successful PUT.

9. **A corrupt chosen Whisper model can be deleted outside the managed model directory.** [goodModel](/Users/cheyrasmussen/jamsesh-p5/jamsesh/hub/src/audio/whisper.ts:131) uses a string prefix check. A checksum-failing `JAMSESH_WHISPER_MODEL` in `~/.jamsesh/models-backup/` matches the prefix `~/.jamsesh/models` and is removed. **Fix:** delete only the exact managed model path after path normalization; never delete an environment-chosen file.

Surface the former error and search all eligible candidates for the latter.
