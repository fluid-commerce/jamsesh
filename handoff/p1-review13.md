## Must fix before shipping

1. **Local Whisper can outlive the hub, and shutdown reports success without reaping it.** [transcribe.ts](/Users/cheyrasmussen/jamsesh-p1/jamsesh/hub/src/audio/transcribe.ts:93) spawns `whisper-server` directly; [stop()](/Users/cheyrasmussen/jamsesh-p1/jamsesh/hub/src/audio/transcribe.ts:108) only sends a signal. [Hub.stop()](/Users/cheyrasmussen/jamsesh-p1/jamsesh/hub/src/hub.ts:171) does not await it and returns the canvas result as though it covers every helper. A hub killed outright also leaves this process without the canvas helpers’ parent watcher. Wrap owned Whisper processes with `withParentWatch`, make its stop await an observed exit, and include that result in `Hub.stop()`. Test graceful shutdown and a killed hub with local Whisper enabled. This also contradicts [SPEC.md](/Users/cheyrasmussen/jamsesh-p1/jamsesh/SPEC.md:126).

2. **A coordinate directive without named counterparts can be closed after talking to the wrong agent.** The generic [create_directive tool](/Users/cheyrasmussen/jamsesh-p1/jamsesh/hub/src/brain/brain.ts:413) permits `coordinate` but supplies no `counterparts`. [exchangeGap()](/Users/cheyrasmussen/jamsesh-p1/jamsesh/hub/src/session.ts:650) then treats *any* agent appearing in linked messages as a counterpart. A target can exchange messages with an unrelated agent and `jam_ack done` succeeds, even when the directive names someone else. Require validated counterparts when creating a coordinate directive; for existing records, do not infer them from messages. Test the wrong-agent exchange.

3. **`stopHelper` still has a false-success path.** [children.ts](/Users/cheyrasmussen/jamsesh-p1/jamsesh/hub/src/children.ts:30) maps a rejected `proc.exited` promise to `true`. No exit was observed, yet `Canvas.stop()` and `Hub.shutdown()` can report reaping complete. Treat rejection as failure, continue the kill attempt, and return `true` only after a resolved exit promise. Add a rejected-exit test.

4. **Bundled Mac recovery remains unverified.** The previous receipt required an owner-run check of a hung visible page, killed hub, restart, and port release. I could not run the bundled Mac app here. Complete that release check before treating the Phase 1 recovery claim as shippable.
