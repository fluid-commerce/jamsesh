## Must fix before shipping

1. **Archived sources can lose their identity.** [files.ts:451](/Users/cheyrasmussen/jamsesh-p7/jamsesh/hub/src/wiki/files.ts:451) chooses a new source ID by checking only `raw/`. Once a source moves to `raw/archive/`, another source with the same title on the same day can take its ID. [readSource():491](/Users/cheyrasmussen/jamsesh-p7/jamsesh/hub/src/wiki/files.ts:491) then returns the new text for old citations, while [pendingSources():481](/Users/cheyrasmussen/jamsesh-p7/jamsesh/hub/src/wiki/service.ts:481) can treat the new source as already ingested. A later archive rename can overwrite the old file. Reserve IDs across both directories and refuse an occupied archive destination. Test reuse of an archived title and verify both citations and ingest state.

2. **A page can land without entering the approval record.** [accept():815](/Users/cheyrasmussen/jamsesh-p7/jamsesh/hub/src/wiki/service.ts:815) writes a page before saving `prop.applied`. If that proposal save fails, a retry that unchecks the page skips the reconciliation branch; dismissal also relies only on `prop.applied` at [settle():718](/Users/cheyrasmussen/jamsesh-p7/jamsesh/hub/src/wiki/service.ts:718). The page remains on disk without its accept log or index update. Separately, [Board.dismiss():393](/Users/cheyrasmussen/jamsesh-p7/jamsesh/hub/src/board.ts:393) reports success even when settlement fails; cleanup waits for a restart. Reconcile landed pages before applying selections or dismissal, and keep settlement retryable while the hub runs. Fault-test proposal-save failure immediately after page rename. The existing partial-accept tests fail on the *next page write*, after the first page was recorded.

3. **People’s edit sources can omit the edit itself.** [editPage():873](/Users/cheyrasmussen/jamsesh-p7/jamsesh/hub/src/wiki/service.ts:873) caps the stored diff at 20,000 characters. A permitted 40,000-character page with one long changed line can produce an edit source containing only “cut here.” With optional git unavailable, the prior text is then absent from the promised edit history. Store the complete bounded diff, or both page revisions, and test a long-line replacement.

4. **Hover bypasses the stage graph’s name budget.** [GraphCanvas.tsx:229](/Users/cheyrasmussen/jamsesh-p7/jamsesh/web/src/wiki/GraphCanvas.tsx:229) limits idle stage labels to 120, but [the hover path:231](/Users/cheyrasmussen/jamsesh-p7/jamsesh/web/src/wiki/GraphCanvas.tsx:231) adds *every* neighbor. A valid 1,500-page star graph requests 1,499 labels; each can scan all 1,500 discs for placement, and [keepDrawing():102](/Users/cheyrasmussen/jamsesh-p7/jamsesh/web/src/wiki/GraphCanvas.tsx:102) repeats the work every frame while hovered. Cap hover labels and use bounded placement work. Browser-test a high-degree node at the vault limit.

- **Should fix:** [fullDiff():775](/Users/cheyrasmussen/jamsesh-p7/jamsesh/hub/src/wiki/service.ts:775) compares the proposal with the *current* page, not the revision used to build the card. After another edit, “Show the whole change” can show a different diff from the approval card. Save the proposed base text or its full diff with the proposal.
- **Should fix:** Hub [slugifyTitle():29](/Users/cheyrasmussen/jamsesh-p7/jamsesh/hub/src/wiki/files.ts:29) truncates to 60 characters; web [slugify():7](/Users/cheyrasmussen/jamsesh-p7/jamsesh/web/src/wiki/markdown.ts:7) does not. Long wiki links can be marked missing in the UI while the hub indexes a valid target. Share one slug rule and test the boundary.
- **Should fix:** [readState():565](/Users/cheyrasmussen/jamsesh-p7/jamsesh/hub/src/wiki/files.ts:565) accepts fractional cursor and offset values as natural numbers. Validate nonnegative safe integers and source IDs in state tables.
